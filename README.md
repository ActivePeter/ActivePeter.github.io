Source for <https://activepeter.github.io> — a procedurally generated voxel world you fly through
to read about my work. Rust + Bevy compiled to WebAssembly; the terrain is generated in the browser.

This repository holds the built site only. The site is rebuilt from the private source repo and
copied here: `index.html`, the wasm/js bundles, `assets/`, and `content.json` (the text blocks —
edit it to change the copy without rebuilding).
