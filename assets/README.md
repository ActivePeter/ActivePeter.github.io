# RBMC assets

The block textures and noise fields in this directory are original procedural
assets generated by [`generate_textures.py`](../../../scripts/generate_textures.py).
They use the workspace's `Apache-2.0` license. The generator reads no
Minecraft, Create, or third-party shader-pack artwork.

Regenerate them with `python3 scripts/generate_textures.py` from `rust_bevy_mc/`.

Water assets follow the existing shader's sampling layout: `blocks/water_still.png`
is a grayscale 16×512 atlas with 32 animation frames; the material supplies its blue
tint. `fx/noises.png` is a seamless 512×512 field of smooth noise, with wave height
in B and slower distortion in RG. A single tinted tile or white-noise replacement
changes the water's color, wave normals, reflections, and underwater refraction.

The WGSL shaders are the browser client's source assets; `dist/` is generated by
Trunk and is not versioned.

For local texture replacements, mirror the desired paths in the sibling
`assets.local/` directory (for example, `assets.local/fx/noises.png`). Trunk applies
these after building, so a rebuild preserves the local appearance. This directory
is ignored by Git; those files retain their own licensing terms.

Set `RBMC_LOCAL_ASSETS=0` to build with only the repository assets. Release packaging
sets this automatically, including when local replacements are present.
